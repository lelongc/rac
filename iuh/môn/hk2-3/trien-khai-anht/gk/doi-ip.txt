# 🏆 BÍ KÍP "THAY MÁU TOÀN TẬP" (ĐỔI IP WAN, LAN, DMZ) & TEST HỆ THỐNG

**Giả định kịch bản đổi đề cực khó của thầy:**
* **WAN (VMnet8 - NAT):** Chuyển sang dải tĩnh `172.16.0.100/24`.
* **LAN (VMnet2):** Chuyển sang dải `10.0.1.0/24`.
* **DMZ (VMnet4):** Chuyển sang dải `10.0.2.0/24` (IP máy Ubuntu đổi thành `10.0.2.10`).

> **💡 Nguyên tắc "Bất Bại":** Làm từ gốc (VMware) ➡️ Tới nhánh (pfSense) ➡️ Tới lá (Win10/Ubuntu) ➡️ Cập nhật Luật (Rules) ➡️ Xóa rác (Clear Cache).

---

### BƯỚC 1: SỬA ĐƯỜNG MẠNG ẢO TRÊN VMWARE (MÁY THẬT)
*Đây là thao tác "đổi biển tên đường" để các máy ảo nhận diện đúng dải mạng mới.*

1.  Mở phần mềm VMware trên máy thật ➡️ **Edit ➡️ Virtual Network Editor** (Bấm *Change Settings* để lấy quyền Admin).
2.  **Sửa mạng WAN (VMnet8 - NAT):**
    * Chọn **VMnet8**. Ô *Subnet IP* nhập: **`172.16.0.0`**.
    * **Cực kỳ quan trọng:** Bấm nút **NAT Settings...** ở giữa. Nhìn xem dòng **Gateway IP** là số mấy (thường VMware sẽ tự đổi thành **`172.16.0.2`**). **Ghi nhớ số này trong đầu.** Bấm OK.
3.  **Sửa mạng LAN & DMZ:**
    * Chọn **VMnet2 (Host-only):** Ô *Subnet IP* nhập **`10.0.1.0`** (Bỏ tích DHCP).
    * Chọn **VMnet4 (Host-only):** Ô *Subnet IP* nhập **`10.0.2.0`** (Bỏ tích DHCP).
4.  Bấm **Apply ➡️ OK** để đóng bảng.



---

### BƯỚC 2: SỬA IP LAN & LẤY LẠI QUYỀN ĐIỀU KHIỂN
*Lúc này Win10 và pfSense vẫn đang "nhớ" IP cũ nên ông vẫn vào WebGUI được.*

1.  Trên máy ảo Win10, vào WebGUI pfSense, chọn **Interfaces ➡️ LAN**.
2.  Sửa *IPv4 Address* thành **`10.0.1.1`** ➡️ Bấm **Save ➡️ Apply Changes**. *(Trình duyệt sẽ xoay vòng và báo mất mạng - Hãy kệ nó!)*.
3.  Bấm **Windows + R** trên Win10 ➡️ gõ `ncpa.cpl`.
4.  Chuột phải vào card mạng ➡️ **Properties ➡️ IPv4**. Sửa thành:
    * IP address: **`10.0.1.10`**
    * Subnet mask: **`255.255.255.0`**
    * Gateway: **`10.0.1.1`**
    * DNS: **`10.0.1.1`**
5.  **Refresh Card Mạng Win10:** Bấm OK lưu lại. Chuột phải vào card mạng chọn **Disable** (đợi xám đi) ➡️ Chuột phải chọn **Enable** để ép Win10 nhận dải mạng mới.
6.  *Mở màn hình đen pfSense, gõ số `5` để **Reboot** một phát cho hệ thống dọn rác và nhận kết nối mới.*
7.  Mở lại trình duyệt trên Win10, truy cập `http://10.0.1.1` để đăng nhập lại pfSense.

---

### BƯỚC 3: CẤU HÌNH IP TĨNH & GATEWAY CHO WAN
*Phải làm kỹ bước này, nếu không pfSense sẽ có IP nhưng "mù đường" ra Internet.*

1.  Trên menu dọc pfSense, chọn **Interfaces ➡️ WAN**.
2.  Tìm dòng **IPv4 Configuration Type**, đổi từ `DHCP` sang **`Static IPv4`**.
3.  Lăn chuột xuống mục *Static IPv4 Configuration*:
    * **IPv4 Address:** Nhập IP tĩnh thầy yêu cầu (Ví dụ: **`172.16.0.100`**), Subnet mask kế bên chọn **`24`**.
4.  **Khai báo Cửa ngõ (Gateway) ra Internet:**
    * Dòng **IPv4 Upstream gateway** ➡️ Bấm nút **Add a new gateway**.
    * **Gateway Name:** Gõ bừa (VD: `GW_VMWARE`).
    * **Gateway IPv4:** Gõ **CHÍNH XÁC** cái số `.2` ông vừa ghi nhớ ở Bước 1 (Ví dụ: **`172.16.0.2`**).
    * Bấm **Add**.
5.  Lăn xuống cuối cùng, bấm **Save ➡️ Apply Changes**.



---

### BƯỚC 4: SỬA IP CỔNG DMZ & MÁY CHỦ UBUNTU

1.  **Trên pfSense:** Vào **Interfaces ➡️ DMZ**.
    * Sửa *IPv4 Address* thành **`10.0.2.1`**.
    * **Trick Sốc điện card DMZ (Tránh kẹt mạng):** Kéo lên trên, **BỎ TÍCH** *Enable interface* ➡️ Save ➡️ Apply. Sau đó **TÍCH CHỌN LẠI** *Enable interface* ➡️ Save ➡️ Apply.
2.  **Trên máy Ubuntu (Dùng màn hình đen):**
    * Gõ: `sudo nano /etc/netplan/00-installer-config.yaml`
    * Sửa `addresses` thành: **`[10.0.2.10/24]`**
    * Sửa `via` (Gateway) thành: **`10.0.2.1`**
    * Bấm **Ctrl+O** (Enter) để lưu, **Ctrl+X** để thoát.
    * Gõ `sudo netplan apply` để nhận IP mới. *(Nếu ping không thông, hãy quay lại WebGUI pfSense dùng trick bật/tắt card DMZ ở trên 1 lần nữa).*



---

### BƯỚC 5: CẬP NHẬT LUẬT (NAT & FIREWALL)
*Đổi IP xong thì phải sửa lại các bảng chỉ đường cũ.*

1.  **Cập nhật Port Forward (Cho khách ngoài vào Web/SSH):**
    * Vào **Firewall ➡️ NAT ➡️ Port Forward**.
    * Mở các Rule SSH (2222) và Web (80) ra sửa.
    * Mục *Redirect Target IP* ➡️ Đổi thành IP mới của Ubuntu là **`10.0.2.10`**. Bấm Save ➡️ Apply.
2.  **Cập nhật Outbound NAT (Cho DMZ ra Internet):**
    * Vào **Firewall ➡️ NAT ➡️ Outbound**.
    * Sửa Rule của DMZ cũ thành dải mạng DMZ mới: **`10.0.2.0/24`**. Bấm Save ➡️ Apply.
3.  **Cập nhật Alias (Nếu có làm bài chặn Rule):**
    * Vào **Firewall ➡️ Aliases**, đổi IP Ubuntu bên trong thành **`10.0.2.10`**. Bấm Save ➡️ Apply.

## 🚀 QUY TRÌNH TEST "BẤT BẠI" (XÁC NHẬN THÀNH CÔNG)

*Sau khi làm xong 5 bước trên, ông thực hiện đúng 4 bài test này để lấy điểm 10 tuyệt đối:*

* **Bài Test 4: Test NAT Port Forwarding (Khách từ Internet truy cập)**

# 🏆 PHẦN 2: CHINH PHỤC TRÙM CUỐI (MULTI-WAN & HA CARP)

Sau khi hệ thống Web nội bộ đã chạy ngon lành, ta tiến hành nâng cấp hệ thống chống đứt cáp và chống chết máy chủ.

## BÀI TẬP 1: MULTI-WAN (CÂN BẰNG TẢI 2 ĐƯỜNG TRUYỀN)
*Mục đích: Cắm thêm đường mạng thứ 2 cho pfSense. Đứt mạng 1 thì tự nhảy sang mạng 2.*

### BƯỚC 1: TẠO WAN 2 BẰNG CÁCH SHARE MẠNG TỪ MÁY THẬT
1.  Mở **Virtual Network Editor** (Trên máy thật).
2.  Bấm **Add Network** ➡️ Chọn **VMnet5**.
3.  Tích chọn **Host-only** ➡️ **TÍCH CHỌN LẠI** ô `Connect a host virtual adapter to this network` ➡️ **BỎ TÍCH** ô `Use local DHCP`. Bấm OK.
4.  Bấm `Windows + R` trên máy thật, gõ `ncpa.cpl`.
5.  Chuột phải vào card mạng **đang có Internet** (Wi-Fi/Ethernet) ➡️ **Properties ➡️ Sharing**.
6.  Tích vào ô *Allow other network users...* ➡️ Chọn cái mạng **VMware Network Adapter VMnet5** vừa tạo. Bấm OK.

### BƯỚC 2: GẮN WAN 2 VÀO PFSENSE
1.  Tắt máy ảo pfSense.
2.  Vào Settings pfSense ➡️ Add ➡️ Network Adapter ➡️ Chọn **Custom: VMnet5**.
3.  Bật pfSense lên.
4.  Vào WebGUI pfSense ➡️ **Interfaces ➡️ Assignments**.
5.  Bấm **Add** để nhận card mới (`OPT1`). Bấm vào nó ➡️ Tích Enable ➡️ Đổi tên thành **`WAN2`** ➡️ IPv4 Configuration Type: **`DHCP`** ➡️ Save ➡️ Apply.

### BƯỚC 3: TẠO LIÊN MINH GATEWAY (CÚ CHỐT)
1.  Vào **System ➡️ Routing ➡️ Gateways**.
    * Edit Gateway WAN1: Dòng Monitor IP gõ `8.8.8.8`. Save.
    * Edit Gateway WAN2: Dòng Monitor IP gõ `8.8.4.4`. Save & Apply.
2.  Chuyển sang tab **Gateway Groups** ➡️ Bấm Add.
    * Group Name: **`MULTI_WAN`**.
    * Gateway Priority: WAN1 chọn `Tier 1`, WAN2 chọn `Tier 1` (Cân bằng tải) hoặc `Tier 2` (Dự phòng).
    * Trigger Level: `Member Down`. Bấm Save ➡️ Apply.
3.  **Ép LAN và DMZ xài liên minh mới:**
    * Vào **Firewall ➡️ Rules ➡️ LAN**. Edit cái Rule "Default allow LAN to any" (dưới cùng). Lăn xuống chọn Display Advanced ➡️ Gateway: Xổ xuống chọn **`MULTI_WAN`**. Save.
    * Chuyển sang tab **DMZ**. Edit Rule "Allow Any". Lăn xuống Display Advanced ➡️ Gateway: Xổ xuống chọn **`MULTI_WAN`**. Save ➡️ Apply.

## BÀI TẬP 2: HIGH AVAILABILITY (HA) - CARP
*Mục đích: Dùng 2 máy pfSense. Máy 1 sập thì máy 2 gánh. Win10 không bị rớt mạng.*

> 📊 **BẢNG QUY HOẠCH IP CARP (CẦN GHI NHỚ)**
> * **LAN:** Máy 1 (`10.0.1.1`) | Máy 2 (`10.0.1.2`) | **IP ẢO CHUNG: `10.0.1.3`**
> * **DMZ:** Máy 1 (`10.0.2.1`) | Máy 2 (`10.0.2.2`) | **IP ẢO CHUNG: `10.0.2.3`**
> * **WAN:** Máy 1 (`172.16.0.100`) | Máy 2 (`172.16.0.101`) | **IP ẢO CHUNG: `172.16.0.111`**

### BƯỚC 1: CLONE MÁY & CÁCH LY (CỰC KỲ QUAN TRỌNG)
1.  Tắt máy **pfSense 1**.
2.  Chuột phải pfSense 1 ➡️ **Manage ➡️ Clone** ➡️ Create full clone ➡️ Đặt tên: **`pfSense 2`**.
3.  Vào Settings của **pfSense 2**: Chọn vào tất cả các card mạng (WAN, LAN, DMZ, WAN2) ➡️ **BỎ TÍCH** ô `Connected` và `Connect at power on`. Bấm OK.
4.  Bật **pfSense 2** lên.

### BƯỚC 2: ĐỔI IP CHO PFSENSE 2 (Tránh xung đột)
Trên màn hình đen của pfSense 2, gõ **`2`** (Set interface IP):
1.  Chọn cổng **LAN**: Đổi thành **`10.0.1.2`** / Subnet `24`.
2.  Chọn cổng **DMZ**: Đổi thành **`10.0.2.2`** / Subnet `24`.
3.  Chọn cổng **WAN**: Đổi thành **`172.16.0.101`** / Subnet `24` / Upstream Gateway: **`172.16.0.2`**.
4.  Làm xong, vào lại Settings pfSense 2, **TÍCH CHỌN LẠI** ô `Connected` cho tất cả card mạng. Bật luôn **pfSense 1** lên.

### BƯỚC 3: TẠO IP ẢO CARP TRÊN CẢ 2 MÁY

**👉 Làm trên pfSense 1 (`10.0.1.1`):**
1.  Vào **Firewall ➡️ Virtual IPs ➡️ Add**.
2.  **LAN:** Type `CARP` | Interface `LAN` | Address: **`10.0.1.3/24`** | Pass: `pfsense` | VHID: `1` | Base Skew: **`0`**. (Save)
3.  **DMZ:** Type `CARP` | Interface `DMZ` | Address: **`10.0.2.3/24`** | Pass: `pfsense` | VHID: `2` | Base Skew: **`0`**. (Save)
4.  **WAN:** Type `CARP` | Interface `WAN` | Address: **`172.16.0.111/24`** | Pass: `pfsense` | VHID: `3` | Base Skew: **`0`**. (Save & Apply).

**👉 Làm trên pfSense 2 (`10.0.1.2`):**
Làm y chang như trên, nhưng **Base Skew điền `100`**:
1.  **LAN:** IP `10.0.1.3/24` | VHID: `1` | Base Skew: **`100`**. (Save).
2.  **DMZ:** IP `10.0.2.3/24` | VHID: `2` | Base Skew: **`100`**. (Save).
3.  **WAN:** IP `172.16.0.111/24` | VHID: `3` | Base Skew: **`100`**. (Save & Apply).
*(Mẹo: Check lại mục Interfaces > WAN xem Upstream Gateway đã là `172.16.0.2` chưa).*

### BƯỚC 4: ÉP HỆ THỐNG XÀI IP ẢO (CÚ CHỐT 10 ĐIỂM)
1.  **Chỉnh Outbound NAT (Phải làm trên CẢ 2 MÁY pfSense):**
    * Vào **Firewall ➡️ NAT ➡️ Outbound**.
    * Chuyển sang **`Manual Outbound NAT...`** (Thủ công) ➡️ Save.
    * Bấm nút Edit (cây bút) vào tất cả các dòng Rule bên dưới.
    * Mục **Translation ➡️ Address**: Đổi thành IP WAN Ảo **`172.16.0.111`**.
    * Bấm Save. Sửa hết các dòng rồi **Apply Changes**.
2.  **Đổi Gateway cho máy con:**
    * **Win10:** Mở `ncpa.cpl` ➡️ Đổi Default Gateway và DNS thành IP ảo LAN: **`10.0.1.3`**. (Tắt bật lại card mạng).
    * **Ubuntu:** Sửa file `/etc/netplan/00-installer-config.yaml` ➡️ Gateway (`via`) đổi thành IP ảo DMZ: **`10.0.2.3`** ➡️ Chạy `sudo netplan apply`.

### QUY TRÌNH TEST CHO THẦY XEM
1. Mở Win10, vào CMD gõ: `ping 8.8.8.8 -t`.
2. Đăng nhập 2 tab pfSense, vào **Status ➡️ CARP**. Trình bày: *"Máy 1 đang là MASTER, máy 2 đang là BACKUP"*.
3. Ra ngoài VMware, tắt phựt (Power Off) máy pfSense 1.
4. Chỉ vào màn hình Win10: *"Thầy xem, ping chỉ rớt đúng 1 nhịp rồi chạy tiếp, máy 2 đã tự động leo lên làm MASTER để gánh mạng ạ!"*.
