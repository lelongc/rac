-----------------------------------------------------------------------------
PHAN II: HUONG DAN DUNG TERMINAL (CMD CUA WINDOWS/ECLIPSE) DE CHAY CO THAM SO
-----------------------------------------------------------------------------
Vi thu muc la "4_Socket_TCP" nhung ten ruot Package lai la "Socket_TCP_Thread", 
ban phai danh lenh chuan de may hieu. Lam dung 3 buoc sau tai Terminal:

1. Chuyen huong vao thu muc goc (DeCuongGiuaKi). Dinh dang tren CMD phai the hien nhu:
      ...> Ptht-tichhop\DeCuongGiuaKi>

2. Bien dich lenh sinh File Class (Voi lenh -d . de no giu nguyen Package ruot):
      javac -encoding UTF-8 -d . 4_Socket_TCP/*.java

3. Chay file bang JVM kem theo danh sach bien tham so args (vd IP):
      java Socket_TCP_Thread.Client 127.0.0.1 8080

-----------------------------------------------------------------------------
PHAN III: QUY TRINH SIEU TOC KHI THI SOCKET (TUAN 5) -> DUNG CHO 80% KHI THI
-----------------------------------------------------------------------------
Tat ca Logic de thi Tuan 5 deu duoc tap trung o [WorkerThread.java] voi TCP
va [UDPServer.java] doi voi UDP.

CACH LAM:
1. Doc de xem cho TCP hay UDP -> Vao thu muc tuong ung Mo file Server ra.
2. Cuon chuot xuong vong lap [while((inputLine = in.readLine()) != null)]
3. Ban se thay:
   DANG 1 (Viet hoa) ... DANG 16 (Toan Mini) ... DANG 20 (OP)
4. De ra dang nao, dung chuot BOI DEN vung comment DANG DO.
5. Bam to hop phim [Ctrl + /] de Mo Khoa Khong Con Comment nua.
6. Luu y vung dang khong thi (hien tai mac dinh mo la DANG 16) phai 
   duoc [Ctrl + /] de vo hieu hoa thanh Comment Xam'. Khong duoc de 2 Dang mo song song.
7. Chay con Server truoc. Sau do sang Client.java bam Run The La Xong.

(LOI DUONG DAN TEP: Cac Code File IO Socket luon can xuat tu thu muc 
Eclispe nen bien DIR da de san la "DeCuongGiuaKi/4_Socket_TCP/". Nho sua them 
thut theo thu muc cha Project cua ban neu bi loi Not Found).
