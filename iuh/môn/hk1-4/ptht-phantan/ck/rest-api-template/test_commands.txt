--------------------------------------------------------------------------------
1. CÁC LỆNH TEST TRÊN POWERSHELL (DÙNG ĐỂ CHỤP MÀN HÌNH NỘP BÀI)
LƯU Ý: Trong PowerShell, dùng cú pháp pipeline | curl.exe để KHÔNG BỊ LỖI JSON!
--------------------------------------------------------------------------------

# 1.1. Lấy toàn bộ danh sách (GET ALL)
curl.exe -s -X GET http://localhost:8080/api/items

# Hoặc nếu đề ghi /api/products hoặc /api/students:
curl.exe -s -X GET http://localhost:8080/api/products
curl.exe -s -X GET http://localhost:8080/api/students

# 1.2. Lấy chi tiết theo ID (GET by ID)
curl.exe -s -X GET http://localhost:8080/api/items/1

# 1.3. Thêm mới đối tượng (POST)
'{"name":"MacBook Pro M3","code":"APL-M3","price":32000000.0,"category":"Laptop","quantity":5,"description":"Apple Silicon"}' | curl.exe -s -X POST http://localhost:8080/api/items -H "Content-Type: application/json" -d @-

# 1.4. Cập nhật đối tượng theo ID (PUT)
'{"name":"MacBook Pro M3 Max","price":45000000.0}' | curl.exe -s -X PUT http://localhost:8080/api/items/4 -H "Content-Type: application/json" -d @-

# 1.5. Xóa đối tượng theo ID (DELETE)
curl.exe -s -X DELETE http://localhost:8080/api/items/2

# 1.6. Tìm kiếm theo từ khóa (GET SEARCH)
curl.exe -s -X GET "http://localhost:8080/api/items/search?keyword=MacBook"

# 1.7. Lọc theo khoảng giá (GET FILTER)
curl.exe -s -X GET "http://localhost:8080/api/items/filter?minPrice=2000000&maxPrice=30000000"


--------------------------------------------------------------------------------
2. CÁC LỆNH TEST BẰNG CMD (COMMAND PROMPT)
--------------------------------------------------------------------------------

# GET ALL
curl -s -X GET http://localhost:8080/api/items

# GET by ID
curl -s -X GET http://localhost:8080/api/items/1

# POST (Trong CMD dùng dấu ngoặc kép bọc JSON và dấu gạch chéo ngược escape \")
curl -s -X POST http://localhost:8080/api/items -H "Content-Type: application/json" -d "{\"name\":\"MacBook Pro M3\",\"code\":\"APL-M3\",\"price\":32000000.0,\"category\":\"Laptop\",\"quantity\":5}"

# PUT
curl -s -X PUT http://localhost:8080/api/items/4 -H "Content-Type: application/json" -d "{\"name\":\"MacBook Pro M3 Max\",\"price\":45000000.0}"

# DELETE
curl -s -X DELETE http://localhost:8080/api/items/2


--------------------------------------------------------------------------------
3. CÁC LỆNH BUILD VÀ ĐÓNG GÓI DOCKER
--------------------------------------------------------------------------------

# Bước 1: Build file JAR từ mã nguồn (chạy tại thư mục chứa pom.xml)
mvn clean package -DskipTests
# Hoặc nếu máy không cài maven, dùng wrapper:
.\mvnw.cmd clean package -DskipTests

# Bước 2: Build Docker Image
# Cú pháp chuẩn đề thi: Username/c2:MaSV (Ví dụ: shima594/c2:23630851)
docker build -t shima594/c2:23630851 .

# Bước 3: Chạy Container từ Image vừa build
docker run -d -p 8080:8080 --name product-service shima594/c2:23630851

# Bước 4: Kiểm tra trạng thái container và logs
docker ps
docker logs -f product-service

# Bước 5: Đẩy lên Docker Hub (nếu đề bài yêu cầu nộp link pull/run công khai)
docker push shima594/c2:23630851

# Lệnh gửi vào hộp chat Zoom / Form nộp bài:
