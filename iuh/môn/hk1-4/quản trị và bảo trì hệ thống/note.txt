4. HƯỚNG DẪN AI CÁCH SỬ DỤNG MCP `vmware-mcp` ĐỂ TỰ ĐỘNG HÓA
----------------------------------------------------------------------------------------------------
File cấu hình MCP: c:\Users\Acer\.gemini\config\mcp_config.json
Mã nguồn MCP:     C:\Users\Acer\.gemini\antigravity-ide\mcp\vmware-mcp (Python venv: mcp==1.29.1)

A. CÁC CÔNG CỤ MCP QUAN TRỌNG NHẤT:
1. `vmrun_list`: Kiểm tra danh sách các máy ảo đang chạy.
2. `vmrun_start`: Bật máy ảo (tham số: vm_id = đường dẫn .vmx, gui = true).
3. `vmrun_stop`:  Tắt máy ảo (tham số: vm_id, hard = false/true).
4. `vmrun_reset`: Khởi động lại máy ảo.
5. `vmrun_snapshot_list`: Xem danh sách snapshot của máy ảo.
6. `vmrun_snapshot_revert`: Khôi phục máy ảo về snapshot gốc trong 1 giây (tham số: vm_id, name = "origin" hoặc "00_CLEAN_BASE").
7. `vmrun_snapshot_take`: Tạo snapshot sao lưu trước khi thi/làm bài.
8. `guest_run` / `vmrun_run`: Chạy lệnh CMD / PowerShell trực tiếp trong máy ảo (ngay cả khi máy ảo chưa có mạng hoặc bị mất IP).
   - Ví dụ: Đổi IP card mạng, cấu hình DNS, bật Service.
9. `guest_copy_to` / `guest_copy_from`: Copy file script cấu hình từ máy thật vào thẳng ổ C:\ của máy ảo.
10. `mks_screenshot` / `vmrun_screenshot`: Tự động chụp ảnh màn hình máy ảo lưu ra máy thật để làm báo cáo nghiệm thu nộp giáo viên.
11. `mks_send_key` / `vmrun_keystrokes`: Gửi phím bấm (Ctrl+Alt+Del, gõ pass, Enter) vào màn hình máy ảo.
12. `ethernet_set_network`: Đổi card mạng máy ảo sang VMnet11, VMnet12, VMnet8 NAT, hoặc Bridged.
