Remote access
telnet
• Dịch vụ cho phép thực hiện truy suất từ xa , bằng dòng
lệnh, sử dụng network virtual terminal
• mô hình client-server
• kết nối tcp
• port 23
• Dịch vụ không mã hóa dữ liệu
• Sử dụng ssh thay thế
• Trên server, dịch vụ telnet được quản lý bởi xinetd
• Với file cấu hình /etc/xinetd.d/telnet
• Trên client thực hiện remote access bằng
telnet   ip_server
• Các gói cài đặt
• Trên server : telnetd
• Trên client : telnet

Remote access
OpenSSH
• Secure Shell (ssh) service
• client-server protocol, port 22
• Chức năng tương tự Telnet
• Mã hóa data 
• Cài đặt và cấu hình OpenSSH server application :
– Gói cài đặt :   openssh-server
=>cung cấp daemon  :  sshd
• File cấu hình :  /etc/ssh/sshd_config
– Quản lý dich vụ :
• Tự động khởi động khi boot ( bằng upstart script)
• Hoặc 
sudo    /etc/init.d/ssh   start | stop|reload|restart
