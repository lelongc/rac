# BÀI 2: DANH SÁCH SẢN PHẨM (WEBSERVICE RESTFUL API + JSON + JQUERY & DOM) - `b2_products`

Thư mục này là bài làm độc lập cho **Bài 2 - Danh sách sản phẩm**.

---

## 🏗️ CẤU TRÚC BÀI 2:
- `src/api/ProductServlet.java`: REST API trả về JSON mảng sản phẩm.
- `src/api/ServerB2.java`: Server 1-click JDK tự chạy trên Eclipse ở cổng `8082`.
- `WebContent/index.html`: Giao diện Bảng sản phẩm HTML.
- `WebContent/js/products.js`: Mã JS DOM & jQuery AJAX (`$.getJSON`).

---

## 🚀 CÁCH CHẠY & NỘP BÀI 2:
1. **Chạy thử ngay trên Eclipse**: Mở `src/api/ServerB2.java` ➔ nhấp chuột phải chọn **Run As ➔ Java Application**, sau đó mở [http://localhost:8082/index.html](http://localhost:8082/index.html).
2. **Nộp bài cho thầy**: Nén toàn bộ thư mục `b2_products` này gửi cho thầy.
