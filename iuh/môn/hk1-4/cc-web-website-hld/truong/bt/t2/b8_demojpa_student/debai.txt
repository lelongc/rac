
--------------------------------------------------------------------------------
Bước 1: Khởi động MySQL Server (nếu chưa chạy) và mở MySQL Workbench.
Bước 2: Tạo Schema CSDL mới trong MySQL:
        Lệnh SQL: CREATE DATABASE b8_db CHARACTER SET utf8mb4;
Bước 3: Xác định tài khoản kết nối:
        - Host: localhost (127.0.0.1)
        - Port: 3306
        - Username: root
        - Password: root
Bước 4: Tạo/Sử dụng project Spring Boot với các dependencies:
        - Spring Data JPA
        - Spring Web
        - MySQL Driver
        - Thymeleaf
Bước 5: Import dự án Maven vào Eclipse:
        File -> Import... -> Maven -> Existing Maven Projects -> Chọn thư mục code.
Bước 6: Import cấu trúc code chuẩn:
        - com.example.demojpa.entity
        - com.example.demojpa.repository
        - com.example.demojpa.service
        - com.example.demojpa.controller
Bước 7: Cập nhật thông tin cấu hình trong file `application.properties`:
        - spring.datasource.url=jdbc:mysql://localhost:3306/b8_db?createDatabaseIfNotExist=true&useSSL=false&serverTimezone=UTC&allowPublicKeyRetrieval=true&characterEncoding=UTF-8
        - spring.datasource.username=root
        - spring.datasource.password=root
        - spring.jpa.hibernate.ddl-auto=update (để tự động sinh bảng)
Bước 8: Khởi động server Spring Boot:
        Run As -> Spring Boot App (chạy file DemojpaApplication.java).
Bước 9: Vào MySQL Workbench bấm nút Refresh (icon xoay tròn 🔄) ở cột Schemas.
Bước 10: Kiểm tra bảng `students` đã được Hibernate tự động tạo trong CSDL `b8_db` chưa.
Bước 11: Kiểm thử (Test) ứng dụng theo 3 cách:
         Cách 1 - Dùng Postman: Test các REST API tại `/api/students` (GET, POST, PUT, DELETE).
         Cách 2 - Dùng Trình duyệt Web (SPA): Mở `http://localhost:8080/index.html` để thao tác trực quan.
         Cách 3 - Dùng Giao diện Thymeleaf SSR: Mở `http://localhost:8080/students`.


III. DANH SÁCH CHỨC NĂNG CẦN ĐẠT ĐỂ LẤY ĐIỂM TỐI ĐA:
--------------------------------------------------------------------------------
1. Quản lý Sinh viên (CRUD):
   [x] Xem danh sách tất cả sinh viên lưu trong CSDL.

   [x] Cập nhật thông tin sinh viên theo ID.
   [x] Xóa sinh viên khỏi CSDL theo ID.

2. Ràng buộc toàn vẹn dữ liệu (JPA Validation):
   [x] ID tự tăng tự động (IDENTITY).
   [x] Tên sinh viên bắt buộc nhập (nullable = false), tối đa 100 ký tự.

3. Khả năng trình chiếu khi thầy gọi lên chấm:
   [x] Trình chiếu trên Postman: Bắn request nhận JSON ngay lập tức.

       để chứng minh dữ liệu đã vào tận ổ cứng trong MySQL Server!
