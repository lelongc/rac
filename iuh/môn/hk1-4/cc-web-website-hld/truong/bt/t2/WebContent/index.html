Bài Tập Web Service RESTful API (JSON & DOM)

Bài 1: Quy Đổi Tiền Tệ (Package bt1_currency) Bài 2: Danh Sách Sản Phẩm (Package bt2_products)

Cấu trúc các Package trong dự án Eclipse:

  • 📦 firstoop: Bài cũ (OOP Person, Student, Teacher, PersonManagement, App).
  • 📦 bt1_currency: RESTful API Web Service quy đổi tiền tệ (CurrencyServlet).
  • 📦 bt2_products: RESTful API Web Service danh sách sản phẩm (ProductServlet).
  • 📦 webserver: Standalone WebServer khởi chạy Server.
