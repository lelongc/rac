# BÀI THỰC HÀNH OOP (FIRST OOP) - DỰ ÁN ĐỘC LẬP `b0_firstoop`

Thư mục này là bài thực hành Lập trình Hướng đối tượng OOP độc lập.

---

## 🚀 HƯỚNG DẪN MỞ & NỘP BÀI:
1. **Mở trên Eclipse**: Chọn **File ➔ Import... ➔ Existing Projects into Workspace** (hoặc *Projects from Folder or Archive*), trỏ tới thư mục `b0_firstoop`.
2. **Chạy thử**: Mở `src/firstoop/App.java` ➔ nhấp chuột phải chọn **Run As ➔ Java Application**.
3. **Nộp bài**: Nén riêng thư mục `b0_firstoop` gửi cho thầy.
