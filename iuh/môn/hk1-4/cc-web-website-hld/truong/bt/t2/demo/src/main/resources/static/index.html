🛠️ Công Nghệ & Kiến Trúc Hệ Thống

Hệ thống Blog Website được xây dựng theo kiến trúc phân tầng chuẩn doanh nghiệp (Layered Architecture: Controller ➔ Service ➔ Repository ➔ Entity), giao tiếp RESTful API & Thymeleaf SSR:

☕ Java 21 🌱 Spring Boot 3.5.x 🗄️ Spring Data JPA (Hibernate) 🐬 MySQL 8.0 🔒 Spring Security 6 & JWT ☁️ Cloudinary API 🍃 Thymeleaf Engine ⚡ MapStruct & Lombok

✨ Các Chức Năng Chính Của Blog Website

🔐 Xác thực & Hồ sơ

Đăng ký, Đăng nhập bảo mật JWT, Đổi mật khẩu, Cập nhật ảnh đại diện (Avatar) và tiểu sử.

📝 Quản lý bài viết

Soạn thảo bài viết mới, phân loại danh mục, gắn thẻ Tags, lưu bản nháp và xuất bản công khai.

❤️ Tương tác cộng đồng

Thả tim (Like/Unlike) bài viết, Bình luận đa cấp, Lưu bài viết vào danh sách yêu thích.

🛡️ Quản trị Admin

Kiểm duyệt bài viết, Khóa/Mở tài khoản vi phạm, Quản lý danh mục bài viết và xem Dashboard thống kê.
