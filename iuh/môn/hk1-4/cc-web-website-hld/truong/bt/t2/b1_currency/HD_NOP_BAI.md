# BÀI 1: QUY ĐỔI TIỀN TỆ (WEBSERVICE RESTFUL API + JSON + JQUERY & DOM) - `b1_currency`

Thư mục này là bài làm độc lập cho **Bài 1 - Quy đổi tiền tệ**.

---

## 🏗️ CẤU TRÚC BÀI 1:
- `src/api/CurrencyServlet.java`: REST API trả về JSON cho Tomcat.
- `src/api/ServerB1.java`: Server 1-click JDK tự chạy trên Eclipse ở cổng `8081`.
- `WebContent/index.html`: Giao diện WebClient.
- `WebContent/js/currency.js`: Mã JS DOM & jQuery AJAX (`$.ajax`).

---

## 🚀 CÁCH CHẠY & NỘP BÀI 1:
1. **Chạy thử ngay trên Eclipse**: Mở `src/api/ServerB1.java` ➔ nhấp chuột phải chọn **Run As ➔ Java Application**, sau đó mở [http://localhost:8081/index.html](http://localhost:8081/index.html).
2. **Nộp bài cho thầy**: Nén toàn bộ thư mục `b1_currency` này gửi cho thầy.
