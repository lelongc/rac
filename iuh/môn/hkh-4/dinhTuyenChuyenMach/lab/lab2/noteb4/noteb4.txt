# BÀI 4: ĐỊNH TUYẾN RIPv2 VÀ CHUYỂN DỰ PHÒNG (FAILOVER)

## 💻 CÂU 1 & CÂU 2: THIẾT LẬP MÔ HÌNH VÀ CẤU HÌNH RIPv2

Có 2 cách để giải quyết câu này: Dùng Web Tool tự động (nhanh, chuẩn 100%) hoặc Gõ tay từng lệnh.

### CÁCH 1: DÙNG WEB TOOL AUTOEVE (KHUYÊN DÙNG)
Copy đoạn "thần chú" dưới đây dán vào Web Tool:
***
Vẽ sơ đồ mạng định tuyến vòng (Ring Topology) gồm 5 Router (Internet, R1, R2, R3, R4) và 3 PC (VPC5, VPC6, VPC7).
YÊU CẦU CẤU HÌNH CHI TIẾT NHƯ SAU:

1. Kết nối Mạng nội bộ (LAN):
- R1 nối với VPC5 qua cáp Ethernet. (Mạng 192.168.1.0/24, R1: 192.168.1.1, VPC5: 192.168.1.10).
- R3 nối với VPC7 qua cáp Ethernet. (Mạng 192.168.3.0/24, R3: 192.168.3.1, VPC7: 192.168.3.10).
- R4 nối với VPC6 qua cáp Ethernet. (Mạng 192.168.4.0/24, R4: 192.168.4.1, VPC6: 192.168.4.10).
- R1 nối với Router Internet. (Mạng 200.200.200.0/24, R1: 200.200.200.1, Internet: 200.200.200.2). Trên Internet tạo Default Route tĩnh trả về mạng 10.0.0.0/8 và 192.168.0.0/16 qua 200.200.200.1.

2. Kết nối Mạng vòng (Ring) giữa các Router:
- R1 nối với R2 bằng cáp Serial (Mạng 10.0.12.0/24, R1: 10.0.12.1, R2: 10.0.12.2).
- R1 nối với R3 bằng cáp Ethernet (Mạng 10.0.13.0/24, R1: 10.0.13.1, R3: 10.0.13.2).
- R2 nối với R4 bằng cáp Ethernet (Mạng 10.0.24.0/24, R2: 10.0.24.1, R4: 10.0.24.2).
- R3 nối với R4 bằng cáp Serial (Mạng 10.0.34.0/24, R3: 10.0.34.1, R4: 10.0.34.2).

3. Cấu hình Định tuyến RIPv2:
- Trên R1, R2, R3, R4: Bật "router rip", "version 2", "no auto-summary". 
- Sử dụng lệnh "network" để quảng bá tất cả các mạng 10.x.x.x và 192.168.x.x của từng Router.
- RIÊNG TRÊN R1: Không quảng bá mạng 200.200.200.0 vào RIP. Thay vào đó cấu hình Default Route trỏ ra Internet (ip route 0.0.0.0 0.0.0.0 200.200.200.2) và dùng lệnh "default-information originate" trong RIP để đẩy đường ra Internet cho cả mạng.
***

### CÁCH 2: CẤU HÌNH THỦ CÔNG (Dựa trên lệnh Tool xuất ra)
Dưới đây là toàn bộ mã cấu hình để chép vào báo cáo.

**1. Router Internet:**
```text
enable
configure terminal
interface e0/0
ip address 200.200.200.2 255.255.255.0
no shutdown
exit
ip route 10.0.0.0 255.0.0.0 200.200.200.1
ip route 192.168.0.0 255.255.0.0 200.200.200.1
end
write memory
```

**2. Router R1:**
```text
enable
configure terminal
interface e0/0
ip address 192.168.1.1 255.255.255.0
no shutdown
interface e0/1
ip address 200.200.200.1 255.255.255.0
no shutdown
interface s1/0
ip address 10.0.12.1 255.255.255.0
no shutdown
interface e0/2
ip address 10.0.13.1 255.255.255.0
no shutdown
router rip
version 2
no auto-summary
network 192.168.1.0
network 10.0.0.0
default-information originate
exit
ip route 0.0.0.0 0.0.0.0 200.200.200.2
end
write memory
```

**3. Router R2:**
```text
enable
configure terminal
interface s1/0
ip address 10.0.12.2 255.255.255.0
no shutdown
interface e0/0
ip address 10.0.24.1 255.255.255.0
no shutdown
router rip
version 2
no auto-summary
network 10.0.0.0
end
write memory
```

**4. Router R3:**
```text
enable
configure terminal
interface e0/0
ip address 10.0.13.2 255.255.255.0
no shutdown
interface e0/1
ip address 192.168.3.1 255.255.255.0
no shutdown
interface s1/0
ip address 10.0.34.1 255.255.255.0
no shutdown
router rip
version 2
no auto-summary
network 192.168.3.0
network 10.0.0.0
end
write memory
```

**5. Router R4:**
```text
enable
configure terminal
interface e0/0
ip address 10.0.24.2 255.255.255.0
no shutdown
interface s1/0
ip address 10.0.34.2 255.255.255.0
no shutdown
interface e0/1
ip address 192.168.4.1 255.255.255.0
no shutdown
router rip
version 2
no auto-summary
network 192.168.4.0
network 10.0.0.0
end
write memory
```

**6. Cấu hình PC:**
```text
! VPC5
ip 192.168.1.10 255.255.255.0 192.168.1.1
save

! VPC6
ip 192.168.4.10 255.255.255.0 192.168.4.1
save

! VPC7
ip 192.168.3.10 255.255.255.0 192.168.3.1
save
```

## 📸 CÂU 3: Show routing table và giải thích các thành phần
**1. Thao tác chụp hình:**
- Mở Console của **Router R1**, gõ lệnh: `show ip route`
- Chụp lại toàn bộ màn hình kết quả trả về.

**2. Giải thích chép vào báo cáo:**
- Bảng định tuyến xuất hiện các mạng có ký tự `R` ở đầu (ví dụ: `R 192.168.3.0/24 [120/1] via 10.0.13.2`). Đây là các dải mạng mà Router R1 đã học được từ các Router khác thông qua giao thức RIP.
- Ký tự `C` (Connected) và `L` (Local) là các mạng cắm trực tiếp vào R1.
- Ý nghĩa thông số `[120/1]`: Số `120` là AD (Administrative Distance) mặc định của RIP. Số `1` là Metric (Hop count), nghĩa là để đến được mạng đích, gói tin chỉ cần nhảy qua đúng 1 Router trung gian nữa.
- Dòng `Gateway of last resort is 200.200.200.2 to network 0.0.0.0` xuất hiện là nhờ lệnh `default-information originate` ta đã cấu hình, giúp báo cho toàn mạng biết đường đi ra Internet. Mạng RIPv2 đã hội tụ thành công.

---

## 📸 CÂU 4: Cho biết đường đi gói tin (Tracert)
**1. Thao tác chụp hình:**
- Mở Console của máy **VPC5**, gõ lệnh sau để kiểm tra đường đi đến máy VPC7:
  `trace 192.168.3.10`
- Chụp lại màn hình kết quả Trace.

**2. Giải thích chép vào báo cáo:**
- Gói tin xuất phát từ VPC5 ➜ R1 (Hop 1) ➜ R3 (Hop 2) ➜ Tới đích VPC7.
- Đây là tuyến đường đi ngắn nhất (chỉ mất 1 khoảng nhảy/hop count) đi tắt qua đoạn cáp nối trực tiếp mạng `10.0.13.0` giữa R1 và R3. Giao thức RIP đã hoạt động chính xác để chọn ra con đường tối ưu nhất.

---

## 📸 CÂU 5: Ngắt kết nối R1 và R3 (Test Failover)
**1. Thao tác "cắt cáp" ngắt kết nối (Tắt cổng mạng):**
- Trong mã lệnh AutoEVE vừa xuất ra, cổng nối trực tiếp sang R3 của con R1 chính là cổng **e0/2**. Ta sẽ tiến hành tắt cổng này.
- Tại màn hình Console của Router **R1**, bạn gõ:
```text
R1# configure terminal
R1(config)# interface e0/2
R1(config-if)# shutdown
R1(config-if)# end

R1# configure terminal
R1(config)# interface e0/2
R1(config-if)# no shutdown
R1(config-if)# end
```

- **Quan trọng:** Chờ khoảng 30 giây đến 1 phút để giao thức RIP tính toán lại đường đi mới.

**2. Thao tác chụp hình và giải thích (Câu 5.a - Show routing table):**
- Mở lại Console của **Router R1**, gõ: `show ip route`
- *Chụp lại màn hình kết quả.*
- **Giải thích chép vào báo cáo:** Nhìn vào dòng `R 192.168.3.0/24`, ta thấy địa chỉ IP Next-Hop đã thay đổi từ `via 10.0.13.2` sang `via 10.0.12.2` (trỏ ngược về Router R2). Số Metric cũng tăng lên thành `[120/2]`. Lý do là đường cáp tắt đã bị đứt, RIP tự động cập nhật bảng định tuyến để đi vòng qua đường R2.

**3. Thao tác chụp hình và giải thích (Câu 5.b - Tracert):**
- Mở lại Console của máy **VPC5**, gõ lại lệnh: `trace 192.168.3.10`
- *Chụp lại màn hình.*
- **Giải thích chép vào báo cáo:** Kết quả Trace cho thấy lộ trình đã dài hơn: `VPC5 ➜ R1 ➜ R2 ➜ R4 ➜ R3 ➜ VPC7`. Do sợi dây R1-R3 bị đứt, gói tin thông minh tự động chuyển hướng đi đường vòng qua R2 và R4 để giữ cho mạng không bị sập. Đây là minh chứng rõ ràng nhất cho tính năng hội tụ và chuyển dự phòng (Failover) của giao thức định tuyến động RIP.

*(Lưu ý: Nếu muốn bật lại mạng như cũ, chỉ việc vào lại `interface e0/2` và gõ `no shutdown`)*
