# PHẦN 1: CHẠY LỆNH CẤU HÌNH VÀ GIẢI THÍCH LỆNH

### 1. Thiết bị R1 (Core Router)
**Lệnh cấu hình:**
```bash
interface e0/0.2, e0/0.3 # Cấu hình Router-on-a-stick
encapsulation dot1Q 2/3 # Gán VLAN cho sub-interface
ip address 192.168.2.1/3 255.255.255.0 # Cấp IP Gateway cho VLAN
ip dhcp pool VLAN2/3/NET100 # Cấu hình DHCP Server cho các mạng nội bộ
router rip; version 2; network ... # Chạy định tuyến RIPv2
ip access-list extended ACL_VLAN2/3 # Cấu hình lọc gói tin (Security)
```
**Giải thích:**
*   **Sub-interfaces:** Sử dụng `dot1Q` để chia cổng vật lý thành nhiều cổng ảo, cho phép R1 định tuyến giữa các VLAN.
*   **DHCP Pools:** Tự động cấp IP cho các thiết bị đầu cuối (PC) trong mạng.
*   **RIPv2:** Giao thức định tuyến động giúp R1 trao đổi bảng định tuyến với R3, đảm bảo các mạng con được học lẫn nhau.
*   **ACL:** Kiểm soát truy cập, giới hạn quyền truy cập của VLAN 2 và VLAN 3 vào các Web Server dựa trên địa chỉ IP và cổng dịch vụ (HTTP/HTTPS).

### 2. Thiết bị R3 (NAT Router)
**Lệnh cấu hình:**
```bash
interface s1/0, s1/1 # Cấu hình cổng kết nối
ip nat inside/outside # Đánh dấu cổng nội bộ và cổng ra Internet
ip nat inside source list 1 interface e0/0 overload # Cấu hình PAT
default-information originate # Quảng bá tuyến đường mặc định qua RIP
```
**Giải thích:**
*   **NAT/PAT:** Chuyển đổi địa chỉ IP nội bộ sang IP của cổng `e0/0` (kết nối Cloud) để truy cập Internet.
*   **Default-information originate:** R3 thông báo cho các Router khác (R1, R2) rằng nó là "cửa ngõ" ra Internet thông qua RIP.

### 3. Thiết bị R2 (Edge Router)
**Lệnh cấu hình:**
```bash
interface e0/0, e0/1 # Cấu hình IP cho các Web Server
router rip; network 172.16.0.0; network 10.0.0.0 # Định tuyến RIP
```
**Giải thích:**
*   R2 đóng vai trò kết nối các Server vào hệ thống mạng chung, sử dụng RIP để quảng bá các dải IP của Server về phía R1 và R3.

### 4. Thiết bị Switch (SW_SERVER & SW_CL)
**Lệnh cấu hình:**
```bash
vtp domain Lab5; vtp mode server/client # Cấu hình VTP
switchport mode trunk/access # Cấu hình cổng Trunk và Access
```
**Giải thích:**
*   **VTP:** Đồng bộ hóa cơ sở dữ liệu VLAN giữa các Switch, giúp quản lý tập trung.
*   **Trunking:** Cho phép các gói tin mang nhãn VLAN đi qua giữa các Switch và Router.

# PHẦN 2: CÁC LỆNH KIỂM TRA (VERIFY) VÀ GIẢI THÍCH OUTPUT

### 1. Kiểm tra bảng định tuyến (Show ip route)
*   **Output:** `R 192.168.2.0/24 [120/1] via 10.0.0.1`
*   **Giải thích:** Chữ `R` thể hiện tuyến đường được học qua giao thức RIP. `[120/1]` là Administrative Distance (120) và Metric (1). Điều này chứng minh R3 đã học được mạng của R1.

### 2. Kiểm tra kết nối (Ping)
*   **Output:** `Sending 5, 100-byte ICMP Echos to 172.16.200.2, timeout is 2 seconds: !!!!!`
*   **Giải thích:** 5 dấu chấm than (`!!!!!`) khẳng định gói tin đã đi và về thành công giữa PC và Web Server, chứng minh cấu hình định tuyến và NAT đã hoạt động chính xác.

### 3. Kiểm tra NAT (Show ip nat translations)
*   **Output:** `inside global 1.1.1.1, inside local 192.168.2.2`
*   **Giải thích:** Bảng này cho thấy IP nội bộ (local) đã được ánh xạ thành công sang IP công cộng (global) thông qua cơ chế PAT trên R3.

# PHẦN 3: BÁO CÁO HOÀN THÀNH

Sau khi thực hiện cấu hình và kiểm tra, hệ thống mạng **Lab_VTP_RIP_NAT** đã hoàn thiện và đáp ứng đầy đủ các yêu cầu đề bài:
1.  **VTP:** Đồng bộ VLAN thành công giữa các Switch.
2.  **Định tuyến:** RIPv2 đã hội tụ, cho phép các phân đoạn mạng (VLAN 2, 3, Server) liên thông hoàn toàn.
3.  **Bảo mật:** ACL đã được áp dụng để hạn chế truy cập từ VLAN 2/3 vào Web Server theo đúng chính sách.
4.  **Internet:** Cơ chế NAT/PAT trên R3 hoạt động ổn định, cho phép các thiết bị nội bộ truy cập ra ngoài.

Hệ thống đã sẵn sàng đưa vào vận hành.
