3. Kiểm tra cấp phát IP (DHCP):
- Trên C_VL2: 'ip dhcp' (Đợi nhận IP 192.168.2.2)
- Trên C_VL3: 'ip dhcp' (Đợi nhận IP 192.168.3.2)
- Trên VPC_R1: 'ip dhcp' (Đợi nhận IP 192.168.100.2)
- Nhớ cấu hình IP tĩnh cho C_VL2 và C_VL3 nếu muốn test ACL chính xác hơn (ví dụ C_VL2 gán 192.168.2.5 để test, 192.168.2.50 để test rớt mạng).
Ví dụ trên VPCS C_VL2:
  + Test thông mạng bình thường: 'ip 192.168.2.5 24 192.168.2.1'

6. Kiểm tra ACL VLAN 2 (C_VL2):
- Đổi C_VL2 thành IP 192.168.2.5 (Nằm trong dải .1 đến .10).
  + 'ping 172.16.200.2' -> THÀNH CÔNG (Thuộc dải được thông mạng bình thường).
- Đổi C_VL2 thành IP 192.168.2.50 (Không thuộc dải .1-.10).
  + 'ping 172.16.200.2' -> THẤT BẠI (Bị chặn Ping).
  + (Tuỳ chọn nếu VPCS hỗ trợ TCP): Gửi request HTTP tới 172.16.200.2 port 80 -> THÀNH CÔNG (Vì chỉ cho phép Web).

7. Kiểm tra ACL VLAN 3 (C_VL3):
- Đổi C_VL3 thành IP 192.168.3.10.
  + 'ping 172.16.200.130' -> THÀNH CÔNG.
- Đổi C_VL3 thành IP 192.168.3.200 (Nằm trong dải bị cấm).
  + 'ping 172.16.200.130' -> THẤT BẠI.
