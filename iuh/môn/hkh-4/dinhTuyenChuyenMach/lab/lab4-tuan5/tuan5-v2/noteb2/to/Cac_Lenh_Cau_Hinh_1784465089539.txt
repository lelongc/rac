configure terminal
no ip cef
interface e0/0
ip address 10.10.10.1 255.255.0.0
ip nat inside
no shutdown
interface e0/1
ip address 20.20.20.1 255.255.0.0
ip nat inside
no shutdown
interface e0/2
ip address dhcp
ip nat outside
no shutdown
router rip
version 1
network 10.0.0.0
redistribute ospf 1 metric 2
default-information originate
router ospf 1
network 20.20.0.0 0.0.255.255 area 0
redistribute rip subnets
default-information originate
access-list 1 permit any
ip nat inside source list 1 interface e0/2 overload
end
write memory
