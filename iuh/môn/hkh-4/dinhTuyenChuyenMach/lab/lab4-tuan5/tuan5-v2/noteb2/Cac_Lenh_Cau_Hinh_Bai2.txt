# CÁC LỆNH CẤU HÌNH THỦ CÔNG - BÀI 2 (LAB 5-6 VLAN, OSPF, RIP, ACL)
=====================================================================
(Tất cả Switch là L2 thuần, Router R1, R2, R3 là L3)

---

## 1. CẤU HÌNH CÁC SWITCH (SW_SERVER, SW_CL1, SW_CL2)
*(LƯU Ý QUAN TRỌNG: Với Switch IOL của EVE-NG, bắt buộc phải gõ lệnh `switchport trunk encapsulation dot1q` trước khi gõ `switchport mode trunk`, nếu không lệnh sẽ bị từ chối).*

```text
enable
configure terminal
! Tắt định tuyến để dùng như Switch L2 thuần tuý
no ip routing
! Tạo các VLAN
vlan 20
 name VLAN20
vlan 30
 name VLAN30
vlan 40
 name VLAN40
exit
```

**Trên SW_CL1 và SW_CL2:**
```text
interface e0/1
 switchport mode access
 switchport access vlan 20
interface e0/2
 switchport mode access
 switchport access vlan 30
interface e0/3
 switchport mode access
 switchport access vlan 40
! Cổng nối uplink
interface e0/0
 switchport trunk encapsulation dot1q
 switchport mode trunk
exit
```

**Trên SW_SERVER:**
```text
interface range e0/0-2
 switchport trunk encapsulation dot1q
 switchport mode trunk
exit
```

## 2. CẤU HÌNH CƠ BẢN VÀ IP TRÊN CÁC ROUTER

### R3 (Router-on-a-stick & RIP):
```text
enable
configure terminal
no ip cef
interface e0/0
 ip address 10.10.10.2 255.255.0.0
 no shutdown
 
interface e0/1
 no shutdown
interface e0/1.20
 encapsulation dot1Q 20
 ip address 220.220.220.1 255.255.255.0
interface e0/1.30
 encapsulation dot1Q 30
 ip address 220.220.230.1 255.255.255.0
interface e0/1.40
 encapsulation dot1Q 40
 ip address 220.220.240.1 255.255.255.0
interface e0/1.1
 encapsulation dot1Q 1 native
 ip address 172.16.1.1 255.255.255.0
exit

! Cấu hình RIP v1
router rip
 network 10.0.0.0
 network 220.220.220.0
 network 220.220.230.0
 network 220.220.240.0
exit
```

### R2 (OSPF & DHCP Server):
```text
enable
configure terminal
no ip cef
interface e0/0
 ip address 20.20.20.2 255.255.0.0
 no shutdown
interface e0/1
 ip address 172.16.0.1 255.255.0.0
 no shutdown
exit

! Cấu hình DHCP cấp cho LAN
ip dhcp pool LAN_172
 network 172.16.0.0 255.255.0.0
 default-router 172.16.0.1
exit

! Cấu hình OSPF
router ospf 1
 network 20.20.0.0 0.0.255.255 area 0
 network 172.16.0.0 0.0.255.255 area 0
exit
```

### R1 (OSPF, RIP, Redistribution, NAT Overload):
```text
enable
configure terminal
no ip cef
interface e0/0
 ip address 10.10.10.1 255.255.0.0
 ip nat inside
 no shutdown
interface e0/1
 ip address 20.20.20.1 255.255.0.0
 ip nat inside
 no shutdown
interface e0/2
 ip address dhcp
 ip nat outside
 no shutdown
exit

! NAT Overload
access-list 1 permit any
ip nat inside source list 1 interface e0/2 overload

! RIP v1
router rip
 network 10.0.0.0
 default-information originate
 redistribute ospf 1 metric 2
exit

! OSPF
router ospf 1
 network 20.20.0.0 0.0.255.255 area 0
 default-information originate
 redistribute rip subnets
exit
```

## 3. CẤU HÌNH ACCESS CONTROL LIST (ACL) TRÊN R3

**VLAN20_ACL:**
```text
ip access-list extended VLAN20_ACL
 deny ip 220.220.220.0 0.0.0.255 220.220.230.0 0.0.0.255
 deny icmp 220.220.220.0 0.0.0.127 220.220.240.0 0.0.0.255 echo
 deny tcp 220.220.220.128 0.0.0.127 220.220.240.0 0.0.0.255 eq 23
 permit ip 220.220.220.0 0.0.0.255 10.10.0.0 0.0.255.255
 permit ip 220.220.220.0 0.0.0.255 20.20.0.0 0.0.255.255
 permit ip 220.220.220.0 0.0.0.255 172.16.0.0 0.0.255.255
 permit ip 220.220.220.0 0.0.0.255 220.220.0.0 0.0.255.255
 deny ip 220.220.220.0 0.0.0.255 any
exit
interface e0/1.20
 ip access-group VLAN20_ACL in
exit
```

**VLAN30_ACL:**
```text
ip access-list extended VLAN30_ACL
 deny ip 220.220.230.0 0.0.0.255 220.220.220.0 0.0.0.255
 permit ip 220.220.230.0 0.0.0.255 10.10.0.0 0.0.255.255
 permit ip 220.220.230.0 0.0.0.255 20.20.0.0 0.0.255.255
 permit ip 220.220.230.0 0.0.0.255 172.16.0.0 0.0.255.255
 permit ip 220.220.230.0 0.0.0.255 220.220.0.0 0.0.255.255
 deny ip 220.220.230.0 0.0.0.255 any
exit
interface e0/1.30
 ip access-group VLAN30_ACL in
exit
```

**VLAN40_ACL:**
```text
ip access-list extended VLAN40_ACL
 deny tcp 220.220.240.0 0.0.0.255 host 10.10.10.1 eq 23
 deny tcp 220.220.240.0 0.0.0.255 host 20.20.20.1 eq 23
 permit ip 220.220.240.0 0.0.0.255 10.10.0.0 0.0.255.255
 permit ip 220.220.240.0 0.0.0.255 20.20.0.0 0.0.255.255
 permit ip 220.220.240.0 0.0.0.255 172.16.0.0 0.0.255.255
 permit ip 220.220.240.0 0.0.0.255 220.220.0.0 0.0.255.255
 deny ip 220.220.240.0 0.0.0.127 any
 deny tcp 220.220.240.128 0.0.0.127 any eq 80
 deny tcp 220.220.240.128 0.0.0.127 any eq 443
 permit ip any any
exit
interface e0/1.40
 ip access-group VLAN40_ACL in
exit
```
