THÔNG TIN SINH VIÊN:
- Tên: Long
- MSSV: 23630851

---------------------------------------------------------------------
1. THIẾT BỊ: SW_SERVER (VTP SERVER)
---------------------------------------------------------------------
enable
configure terminal
vtp domain Long
vtp password 23630851
vtp version 2
vtp mode server
vlan 2
 name IT
vlan 3
 name IS
vlan 4
 name SE
vlan 5
 name CS
interface range e0/0 - 3
 switchport trunk encapsulation dot1q
 switchport mode trunk
 no shutdown
end
write memory

5. CÁC LỆNH KIỂM TRA (VERIFICATION COMMANDS)
---------------------------------------------------------------------
Trên các Switch:

show vlan brief
show interface trunk

Kiểm tra Ping từ VPC2_1 (VLAN 2):
ping 192.168.0.12 (Thành công - cùng VLAN 2 trên SW khác)
ping 192.168.0.3 (Thất bại - khác VLAN)
