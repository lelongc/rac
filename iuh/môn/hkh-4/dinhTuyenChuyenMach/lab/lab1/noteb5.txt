Chào anh Long, làm Bài 5 từ một trang Lab trắng tinh (from scratch) là một thử thách rất thú vị vì nó giống hệt thực tế khi anh thiết lập mạng cho một công ty nhiều chi nhánh.

Do hình sơ đồ bài 5 **chưa có các địa chỉ IP**, tôi sẽ tự thiết kế một bộ IP chuẩn và cực kỳ dễ nhớ để anh gõ theo. Anh chỉ cần làm y chang từng bước dưới đây là xong trọn vẹn bài Homework này nhé!

### BƯỚC 1: QUY HOẠCH IP & CẮM DÂY TRÊN SƠ ĐỒ

Trước tiên anh lôi đủ 4 Router, 4 Switch và 4 PC ra màn hình, cắm dây theo quy tắc (và quy hoạch IP) sau:

* **A.Building:** LAN `192.168.10.x` (Cắm e0/0 xuống SW). Nối Serial s1/0 sang B.
* **B.Building (Trung tâm):** LAN `192.168.20.x` (Cắm e0/0 xuống SW). Nối Serial s1/0 sang A. Nối Serial s1/1 sang C. Nối Serial s1/2 lên Internet.
* **C.Building:** LAN `192.168.30.x` (Cắm e0/0 xuống SW). Nối Serial s1/1 sang B.
* **Internet:** Mạng ngoài `8.8.8.x` (Cắm e0/0 xuống SW). Nối Serial s1/2 xuống B.
* **Mạng nối các Router (WAN):** A nối B (`10.0.1.x`), C nối B (`10.0.2.x`), B nối Internet (`200.200.200.x`).

*(Sau khi nối dây xong, anh quét đen tất cả, nhấp chuột phải chọn **Start Selected**).*

### BƯỚC 2: CẤU HÌNH IP CHO CÁC ROUTER TỪ ĐẦU

Anh mở lần lượt Console của 4 Router lên và copy/paste chính xác các khối lệnh sau:

**1. Router A.Building:**

```text
enable
configure terminal
interface e0/0
ip address 192.168.10.1 255.255.255.0
no shutdown
exit
interface s1/0
ip address 10.0.1.1 255.255.255.0
no shutdown
end
wr

```

**2. Router B.Building (Cục này có 3 cổng Serial):**

```text
enable
configure terminal
interface e0/0
ip address 192.168.20.1 255.255.255.0
no shutdown
exit
interface s1/0
ip address 10.0.1.2 255.255.255.0
no shutdown
exit
interface s1/1
ip address 10.0.2.1 255.255.255.0
no shutdown
exit
interface s1/2
ip address 200.200.200.1 255.255.255.0
no shutdown
end
wr

```

**3. Router C.Building:**

```text
enable
configure terminal
interface e0/0
ip address 192.168.30.1 255.255.255.0
no shutdown
exit
interface s1/1
ip address 10.0.2.2 255.255.255.0
no shutdown
end
wr

```

**4. Router Internet:**

```text
enable
configure terminal
interface e0/0
ip address 8.8.8.1 255.255.255.0
no shutdown
exit
interface s1/2
ip address 200.200.200.2 255.255.255.0
no shutdown
end
wr

```

### BƯỚC 4: ĐỊNH TUYẾN TĨNH (STATIC ROUTING) CHO BÀI 5

Đây là linh hồn của bài Homework này. Phải định tuyến đúng thì từ A mới ra được Internet!

**1. Router A.Building & C.Building (Mạng biên):**
Đẩy hết mọi gói tin không xác định về hướng Router B bằng Default Route.

* **Trên A.Building:**
```text
configure terminal
ip route 0.0.0.0 0.0.0.0 10.0.1.2
end
wr

```


* **Trên C.Building:**
```text
configure terminal
ip route 0.0.0.0 0.0.0.0 10.0.2.1
end
wr

```



**2. Router B.Building (Mạng trung tâm):**
Chỉ đường cụ thể xuống LAN của A, LAN của C, và Default Route lên Internet.

```text
configure terminal
ip route 192.168.10.0 255.255.255.0 10.0.1.1
ip route 192.168.30.0 255.255.255.0 10.0.2.2
ip route 0.0.0.0 0.0.0.0 200.200.200.2
end
wr

```

**3. Router Internet:**
Phải biết đường quay ngược về 3 dải mạng nội bộ (A, B, C) thông qua cục B.

```text
configure terminal
ip route 192.168.10.0 255.255.255.0 200.200.200.1
ip route 192.168.20.0 255.255.255.0 200.200.200.1
ip route 192.168.30.0 255.255.255.0 200.200.200.1
end
wr

```

### BƯỚC 5: KIỂM TRA & CHỤP HÌNH BÁO CÁO

Bây giờ mạng đã thông hoàn toàn từ trong ra ngoài thế giới (Internet)!

> 📸 **HÌNH 1: Bảng định tuyến (Yêu cầu "Show routing table")**
> * Tại Router **B.Building**, gõ `show ip route` và chụp lại.
> * **Giải thích báo cáo:** Chữ 'S*' đại diện cho đường Default Route hướng ra Internet (200.200.200.2). Chữ 'S' đại diện cho Static Route hướng xuống 2 tòa nhà A và C. Các mạng có chữ 'C' là mạng kết nối trực tiếp.
> 
> 

> 📸 **HÌNH 2: Đường đi gói tin (Yêu cầu "Cho biết đường đi gói tin")**
> * Tại máy **C1**, gõ lệnh: `trace 8.8.8.8` (Chờ chạy xong).
> * Gõ tiếp lệnh Ping: `ping 8.8.8.8` và chụp lại toàn bộ màn hình này.
> * **Giải thích báo cáo:** Gói tin từ PC C1 ở Tòa nhà A đi ra thế giới (Internet) thành công. Lộ trình gói tin đi qua: Router A.Building -> Router B.Building -> Router Internet -> PC C4.
>
