# BẢNG TRA CỨU NHANH - THI GIỮA KÌ

## CÔNG THỨC TÍNH TOÁN

### Dung lượng File

```
Image: W × H × BitsPerPixel ÷ 8 (bytes)
Video: Bitrate × Duration ÷ 8 (bytes)
Audio: SampleRate × BitDepth × Channels × Duration ÷ 8 (bytes)
```

### Chuyển đổi đơn vị

```
1 KB = 1,024 bytes
1 MB = 1,024 KB
1 GB = 1,024 MB
1 kHz = 1,000 Hz
1 MHz = 1,000 kHz
```

## THÔNG SỐ CHUẨN

### Resolution Standards

- **SD**: 720×480 (NTSC), 720×576 (PAL)
- **HD**: 1280×720
- **Full HD**: 1920×1080
- **4K UHD**: 3840×2160
- **8K**: 7680×4320

### Frame Rates

- **Cinema**: 24 fps
- **PAL Video**: 25 fps
- **NTSC Video**: 30 fps
- **Gaming**: 60 fps, 120 fps

### Audio Standards

- **CD Quality**: 44.1 kHz, 16-bit
- **Professional**: 48 kHz, 24-bit
- **Studio**: 96 kHz, 24-bit

### Color Depths

- **1-bit**: 2 colors (B&W)
- **8-bit**: 256 colors
- **16-bit**: 65,536 colors
- **24-bit**: 16.7M colors (True Color)
- **32-bit**: 24-bit + 8-bit alpha

## FILE FORMATS

### Image

| Format | Type        | Best Use                   |
| ------ | ----------- | -------------------------- |
| JPEG   | Lossy       | Photos, web                |
| PNG    | Lossless    | Graphics, transparency     |
| GIF    | Indexed     | Animation, simple graphics |
| TIFF   | Lossless    | Print, archival            |
| RAW    | Unprocessed | Professional photography   |

### Video

| Format | Container | Best Use        |
| ------ | --------- | --------------- |
| MP4    | H.264/AAC | Web, mobile     |
| MOV    | Various   | Apple ecosystem |
| AVI    | Various   | Windows legacy  |
| MKV    | Various   | High quality    |
| WebM   | VP8/VP9   | Web streaming   |

### Audio

| Format | Type         | Best Use     |
| ------ | ------------ | ------------ |
| MP3    | Lossy        | General use  |
| AAC    | Lossy        | Apple, video |
| WAV    | Uncompressed | Professional |
| FLAC   | Lossless     | Audiophile   |
| OGG    | Lossy        | Open source  |

## QUICK CALCULATIONS

### Common Resolutions (24-bit)

- **1920×1080**: ~6.2 MB uncompressed
- **1280×720**: ~2.8 MB uncompressed
- **640×480**: ~921 KB uncompressed

### Bitrate Guidelines

- **SD Video**: 1-3 Mbps
- **HD Video**: 3-8 Mbps
- **4K Video**: 15-25 Mbps
- **Audio (MP3)**: 128-320 kbps
- **Audio (CD)**: 1,411 kbps

### Storage Requirements (1 hour)

- **SD Video**: ~1-3 GB
- **HD Video**: ~3-8 GB
- **4K Video**: ~15-25 GB
- **CD Audio**: ~600 MB

## KEYBOARD SHORTCUTS

### Common Operations

- **Ctrl+C**: Copy
- **Ctrl+V**: Paste
- **Ctrl+X**: Cut
- **Ctrl+Z**: Undo
- **Ctrl+Y**: Redo
- **Ctrl+S**: Save
- **Ctrl+Shift+S**: Save As

### Timeline (Video/Audio)

- **Space**: Play/Pause
- **J/K/L**: Rewind/Pause/Fast Forward
- **I/O**: Set In/Out points
- **Ctrl+K**: Split/Cut
- **Delete**: Remove selection

## TROUBLESHOOTING

### Common Issues

- **File won't open**: Check format support
- **Poor quality**: Check compression settings
- **Large file size**: Increase compression
- **Sync issues**: Check sample rates match
- **Color problems**: Check color profiles

### Performance Tips

- **Preview quality**: Lower for editing
- **Proxy files**: Use for large media
- **RAM**: More is better for video
- **Storage**: SSD for media files
